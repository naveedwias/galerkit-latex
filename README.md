# galerkit LaTeX documents

LaTeX sources (and compiled PDFs) of the reports written alongside the galerkit code
(https://github.com/naveedwias/galerkit). The code repository holds no LaTeX files.

| document | PDF | content |
|---|---|---|
| `convection_diffusion/sv_efficiency_proof.tex` (+ `numeric.tex`) | `sv_efficiency_proof.pdf` | guaranteed SV-type a posteriori estimator for AFC, efficiency proof and numerical results |
| `convection_diffusion/bjk16_reproduction.tex` | `bjk16_reproduction.pdf` | reproduction of Barrenechea, John & Knobloch, SINUM 54 (2016), Section 8 |
| `navier_stokes/3d/numerical_example_3d.tex` | (not built: needs the `siunitx` package) | 3D Navier-Stokes numerical example |

Build: `pdflatex <file>.tex` (three times for references) inside the document's folder.

`tables/*.tex` and `figures/*` are generated by scripts in galerkit and copied here:

- `examples/convection_diffusion/sv_numerics/make_figures.py`, `make_exp36_figures.py` (SV estimator)
- `examples/convection_diffusion/2d/afc_bjk16/make_report.py --dest <this repo>/convection_diffusion` (BJK16)
